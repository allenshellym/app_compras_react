# 🛒 Lista de Compras — React Native com Expo

Este é um aplicativo de controle de lista de compras, desenvolvido com **React Native** utilizando o **Expo Router**, com interface moderna, navegação em abas e persistência de dados local.

## ✨ Funcionalidades

- ✅ **Cadastro de itens** com descrição e quantidade
- 📋 **Listagem dos itens cadastrados**
- 📝 **Edição de itens existentes** (campos preenchidos automaticamente)
- ✅ **Marcar item como comprado**, com destaque visual
- ❌ **Excluir itens** da lista
- 💾 **Persistência local** dos dados com `AsyncStorage`

---

## 💡 Tecnologias utilizadas

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [Expo Router](https://expo.github.io/router/)
- [AsyncStorage](https://github.com/react-native-async-storage/async-storage)

---

## 🧭 Navegação

O app possui navegação por abas:

- **Lista de compras:** Exibe todos os itens, com opções de marcar como comprado, editar ou excluir.
- **Adicionar itens:** Permite cadastrar novos itens ou editar itens existentes.
